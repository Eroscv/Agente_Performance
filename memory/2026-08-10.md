## Bugs corrigidos

### 1. Gemini quota diária — skip imediato
- **Problema:** cada mensagem fazia 3 retries no Gemini (14s de espera) antes de cair pro Claude
- **Fix:** `_gemini_quota_skip_until` em `llm/client.py` — detecta `retryDelay > 3600s`, seta skip de 12h, vai direto ao Claude
- **Commit:** `e85a75a`

### 2. NOT NULL constraint em compact_history
- **Problema:** `compact_history_before_expiry` em `memory/shared_memory.py` falhava para 15+ usuários
- **Fix:** INSERT passou a incluir `created_at` (ISO UTC) e `created_at_ts` (epoch float)
- **Commit:** `e85a75a`

### 3. ImageAgent sem proteção de quota
- **Problema:** `image_agent.py` chamava Gemini diretamente, sem herdar o skip de quota
- **Fix:** verifica `_gemini_quota_skip_until` antes de chamar; Claude envia mensagem pedindo que cliente descreva a imagem
- **Decisão:** análise visual é exclusiva do Gemini — Claude é só aviso de indisponibilidade
- **Commit:** `1afefc7`

### 4. Cupom BEMVINDA sendo oferecido a clientes recorrentes
- **Problema:** todos os agentes tinham instrução "SEMPRE mencionar — independente de ser novo ou recorrente"
- **Fix:** corrigido em `_vendas.py`, `_produto.py`, `_geral.py`, `_logistica.py`, `_pagamento.py` — cupom só para novos clientes
- **Commit:** `50c4b62`

## Melhorias implementadas

### 5. Classificador de intent — GERAL de 45% para ~15%
- Novas regras em `fast_classifier.py`: "Já paguei" → PAGAMENTO, cancelar assinatura composta → ASSINATURA, "não consigo comprar" → VENDAS, alterar endereço → LOGISTICA
- Prompt do LLM reforçado: GERAL é última opção explícita
- 13/13 casos testados antes do deploy
- **Commit:** `98c7c8f`

### 6. Pedido duplicado → handoff automático para Jana
- Padrões adicionados no `_REENVIO_RE` do orchestrator
- Cobre: "recebi dois produtos", "cobrado duas vezes", "pedido duplicado", "veio duplo"
- Falsos positivos protegidos: "quero comprar dois produtos" não ativa
- 15/15 casos testados
- **Commit:** `27144b6`

### 7. 5 melhorias de qualidade (commit único `b16ed80`)
- **banned_expression → severity=fix:** 17 expressões substituídas automaticamente (ex: "Que maravilha!" → "ótimo", "Boa pergunta" → removida)
- **Quota Gemini persiste entre restarts:** salvo em `/tmp/gemini_quota_skip.txt` (volátil — ver ponto de atenção abaixo)
- **Anti-loop em tempo real:** 2ª repetição idêntica nas últimas 2h → escala para Jana com motivo `LOOP_DETECTADO`
- **Jana triggers limpos:** parcelamento, frete, assinatura-info removidos dos triggers — Flora resolve ela mesma

### 8. Robustez — 3 fixes críticos (commit `4b8d245`)
- **LimitNOFILE=65536 no systemd:** eliminação dos 437 erros `OSError: Too many open files` (limite era 1024)
- **Circuit breaker no orchestrator:** pipeline inteiro do `handle()` protegido; 10 `except+pass` → `logger.warning`; fallback retorna mensagem amigável ao cliente
- **Webhook /test com timeout 30s:** `ThreadPoolExecutor` com `future.result(timeout=30)`, sempre retorna HTTP 200
