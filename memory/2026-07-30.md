## chatbot_maximo — Novo Projeto

### Repositório
- `Eroscv/chatbot_maximo` (privado)
- Clonado em `/home/ubuntu/.openclaw/workspace/chatbot_maximo/`
- Stack: Python 3.12 + FastAPI + Whapi (WhatsApp) + Supabase (CRM)
- Cliente: Máximo Serviço (empresa de facilities — limpeza, portaria, recepção, etc.)

### Fluxo implementado (completo até 18:30 UTC)
```
Lead manda msg
  └── Boas-vindas (Quero contratar / Quero um emprego)
        ├── Emprego → link trabalhe-conosco + move card stage be979158-7b03-455b-881f-ec493ef4e79f
        └── Contratar → "Você é PJ?" (Sim/Não)
              ├── Não → encerramento "Só atendemos PJ..."
              └── Sim → menu: Limpeza/Portaria/Recepção/Copa/Vigilância desarmada
                          └── cidade/bairro (texto livre)
                                └── CNPJ (texto livre)
                                      └── "Prefere receber por WhatsApp ou e-mail?"
                                            ├── WhatsApp → concluído ✅
                                            └── E-mail → aguarda e-mail → concluído ✅
```

### Contexto/Estado
- Estado em memória (`_CONVERSATION_STATE` dict) — sem banco, reinicia com o processo
- Contexto acumula: `state`, `nome`, `card_id`, `servico`, `cidade`, `cnpj`, `canal`, `email`
- Estados: `new → welcome → pj → servicos → cidade → cnpj → canal → concluido`
- Ciclo numerado 0-7 para a planilha

### CRM (Supabase Edge Functions)
- `crm_client.py` com métodos: `card_exists`, `create_card`, `update_card`, `move_card`
- URL base: env `CRM_BASE_URL`
- Endpoints: `/api-cards-get`, `/api-cards-create`, `/api-cards-update`, `/api-cards-move`
- Card atualizado a cada etapa do fluxo (descrição + campos específicos)
- Stage emprego: `be979158-7b03-455b-881f-ec493ef4e79f`
