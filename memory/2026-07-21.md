# Memória — 2026-07-21

## Agente de Performance Guará — Sessão de Desenvolvimento

### Subagente de Relatoria — Alterações no Builder

Trabalhamos extensivamente no pipeline do relatório semanal (`relatorio/builder.py`). Resumo das mudanças:

#### Seções removidas (ambos os pipelines — semanal e mensal)
- 📋 Desempenho por Campanha
- 🏆 Top Campanhas por ROAS
- 📊 Resumo Executivo
- 🚨 Alertas Automáticos
- 📅 Planejamento Q3 2026 — Meta Ads
- 🎨 Planejamento Criativo
- 📊 Tendência Últimas 4 Semanas (WoW) — substituída por Comparativo com Período Anterior

#### Alterações nas tabelas existentes
- **💰 Alocação Budget Canais:** adicionada coluna `% do Total`
- **📊 Métricas de Site:** adicionada coluna `Receita Total Shopify` (via `valor_compras` do Meta como proxy; campo reservado para Shopify direto)
- **📦 Pedidos por SKU:** expandida para 5 colunas: SKU / Pedidos / Receita / % Pedidos / % Receita
- **🗺️ Pedidos por Estado:** mesmas 5 colunas com % calculados
- **👥 SKU de Entrada (Recompras):** convertida de lista para tabela com colunas SKU / Recompras / % das Recompras

#### Novas funcionalidades
- **🔽 Funil de Conversão:** movido para o início do relatório semanal
- **📈 Comparativo com Período Anterior:** adicionadas métricas Invest. Total (Meta+imposto+Google), Receita Shopify, MER
- **📅 Evolução Mensal Jan/2026:** tabela com todos os meses desde janeiro, colunas Invest. Meta / Invest.+Imposto / Receita Meta / Receita Shopify / MER / ROAS / Compras

### Módulo Shopify (`shopify/client.py`) — CRIADO

Integração completa com a API Shopify da Source Of Brasil:
- **Store:** `source-of-brasil`
- **Token:** em `.env` como `SHOPIFY_TOKEN`
- **Funções:**
  - `pedidos_por_sku(data_inicio, data_fim)` → lista {sku, pedidos, receita}
  - `pedidos_por_estado(data_inicio, data_fim)` → lista {estado, pedidos, receita}
  - `recompras_por_sku(data_inicio, data_fim)` → lista {sku, recompras, pct_recompras}
  - `assiduidade_clientes(data_inicio, data_fim)` → distribuição por faixas de pedidos
  - `receita_total(data_inicio, data_fim)` → float
  - `metricas_site(data_inicio, data_fim)` → KPIs para tabela Métricas de Site
  - `resumo_periodo(data_inicio, data_fim)` → KPIs consolidados
- Paginação cursor-based automática, retry em 429, lookup de `orders_count` via endpoint `/customers/`
- Fallback para placeholder se Shopify indisponível

### Integração Shopify no Builder
- **Semanal:** pedidos_por_sku, pedidos_por_estado, recompras_por_sku, assiduidade_clientes, metricas_site integrados
- **Mensal:** mesmo conjunto integrado (bug corrigido — antes só estava no semanal)
- Métricas de Site: Ticket Médio, Novos Clientes, CAC, % Desconto, Pedidos >R$300, Receita Total Shopify populados com dados reais

### Sincronização Automática da Planilha
- `loader_sheets.py` agora expõe `carregar_sheets()` chamável programaticamente
- `gerar_relatorio_semanal()` e `gerar_relatorio_mensal()` chamam `carregar_sheets()` automaticamente antes de processar
- Dados atualizados até **20/07/2026** na tabela `campanhas`
- Correção: dados da planilha (ads_diario) sincronizados para tabela `campanhas` via view/mapeamento

## POD Kombucha — Google Ads — Novo Cliente (2026-07-21)

### Integração
- **Planilha:** `https://docs.google.com/spreadsheets/d/1Vj3Zt1ZPk5nH_bBbdm1gna0cMC85PGN-pBtCKr_UJ50/export?format=csv`
- **Colunas:** Day, Clicks, Cost, Impr., Conv. value, Conversions, Campaign, Campaign ID, Campaign type
- **Período dados:** 26/07/2025 → 20/07/2026 (1.159 linhas)
- **Tabela banco:** `pod_gads_diario` (TOTALMENTE ISOLADA da Source Of)
- **Loader:** `db/loader_pod.py`
- **Builder relatório:** `relatorio/builder_pod.py`

### Scripts de Cron
- `scripts/cron_relatorio_pod.py` — relatório POD isolado (`--periodo diario|semana|mes`)
- `scripts/cron_todos_relatorios.py` — dispara AMBOS os clientes em sequência
  - `--cliente source_of|pod_kombucha|todos`
  - `--periodo diario|semana|mes`
  - `--no-notion` para dry run

### Crons Agendados
- Toda segunda 08:00 BRT: `cron_todos_relatorios.py --periodo semana`
- Todo dia 1 do mês 08:00 BRT: `cron_todos_relatorios.py --periodo mes`

### Slack — Âncora + Thread (2026-07-21)
- **Módulo:** `slack/poster.py`
- **Fluxo:** mensagem âncora no canal → relatório DETALHADO como reply na thread
- **Canal:** `performance` (ID: `C05SFND7R1D`) — configurado via `SLACK_CHANNEL=performance` no `.env`
- **Âncora:** `📊 Relatório Semanal · Source OF · Meta Ads\n_período_`
- **Thread:** tabelas alinhadas com KPIs, funil, métricas avançadas, campanhas, link Notion
- **Bot Token:** `SLACK_BOT_TOKEN` no `.env` (API Web, não webhook)
- **Fallback:** `postar_webhook_fallback()` via `SLACK_WEBHOOK_URL` se bot API falhar
- Erro anterior resolvido: `FLORA_SLACK_CHANNEL=#performance-flora` estava sendo lido com `#`, canal correto é `performance`
