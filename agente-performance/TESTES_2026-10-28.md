## Bloco 7 — data_verifier (Fact-check + Confidence + Evidence)

**Objetivo:** Cada resposta gerada pelo agente passa por 3 camadas de verificação antes de ser entregue ao usuário.

### 7.1 Fact-check Numérico

Extrai todos os valores numéricos da resposta e verifica rastreabilidade contra os dados brutos.

| Cenário | Resultado | Detalhe |
|---|---|---|
| Dados reais na resposta → fact-check OK | ✅ | 3/3 rastreáveis (100%) |
| Números inventados → detectado | ✅ | `confidence` degradado para `medium` |

**Lógica de rastreabilidade:**
- Match direto com tolerância de ±2%
- Arredondamento de milhar BR (`R$ 8.901` → valor `8901.20`)
- Ponto-como-milhar BR (`8.901` = float → real `8901`)
- Soma de dois valores presentes
- Razão (ROAS = receita/investimento)
- Percentuais derivados (CTR)

### 7.2 Confidence Check

| Cenário | Resultado | Score | Nível |
|---|---|---|---|
| Dados completos, BQ OK, fact-check OK | ✅ | 0.91 | 🟢 alta |
| Fact-check com >30% não rastreáveis | ✅ degradado | 0.60 | 🟡 média |
| `confidence=low` do orchestrator | ✅ | 0.28 | 🔴 baixa |

### 7.3 Evidence Stamp

| Teste | Resultado | Exemplo |
|---|---|---|
| Stamp gerado em toda resposta | ✅ | `_Fonte: BigQuery ✅ · Período: 2026-10-20 → 2026-10-27 · Confiança: 🟢 alta_` |

## Notas de Diagnóstico

### Por que `top_campanhas_roas` retorna 0 rows?
O período `2026-10-01→27` com `investimento >= 100` não retornou campanhas no teste — dados do período podem estar sob outro threshold ou campanhas foram pausadas. Não é um erro de código: `resumo_periodo` para o mesmo período retornou dados corretamente.

### Latência BQ vs SQLite
Consultas BQ levam 1.4–6s (primeira consulta: cold start do cliente BQ). SQLite era <50ms. O tradeoff é intencional — BQ é a fonte autoritativa e o tempo adicional é aceitável para uma ferramenta analítica de uso assíncrono no Slack.

### Fact-check: falsos positivos
O fact-check numérico pode gerar falsos positivos em respostas com muitos números derivados (somas de somas de somas). O limiar atual de 70% de rastreabilidade foi calibrado empiricamente — abaixo disso confidence degrada para `medium` (não `low`), evitando alarmes excessivos.
